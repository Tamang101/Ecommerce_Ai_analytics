# Overview Of Project
##This project analyzes an e-commerce transaction dataset to uncover sales trends, customer behavior, and revenue patterns.
##It demonstrates data cleaning, exploratory analysis, and customer segmentation using Python and SQL — skills directly transferable to financial and banking data analytics.

# Tools & Libraries

## Python, Pandas, NumPy, Matplotlib, Seaborn, Plotly, MySQL

# Dataset Overview
## The dataset contains 525,000+ transactions with columns such as:

## Invoice – transaction identifier

## StockCode – product code

## Description – product name

## Quantity – number of units sold

## Price – price per unit

## Customer ID – unique customer

## Country – customer location

## InvoiceDate – transaction timestamp

# Data Cleaning

## Handled missing values in Customer ID and Description

## Removed duplicates and canceled transactions

## Converted InvoiceDate to datetime and extracted year/month

## Created TotalPrice = Quantity × Price

## Ensured a clean dataset for customer and revenue analysis
